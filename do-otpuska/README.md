# «До отпуска» — приложение-отсчёт для Жени ✈️

Таймер до приезда, северное сияние, снег, солдатик идёт к самолёту.
Когда время выйдет, солдатик поднимается по трапу, и самолёт улетает.

- `www/index.html` — само приложение (его же можно просто открыть в браузере);
- `android/` — Android-проект (Capacitor), из него собирается APK;
- `assets/`, `icon-src/` — иконка-самолётик и заставка.

Настройки спрятаны под шестерёнкой ⚙︎ в правом верхнем углу: заголовок,
дата приезда, дата начала пути. Там же кнопка **«Посмотреть, как улетит
самолёт»**: она показывает финал заранее, а потом всё возвращается обратно.
Если тапнуть по солдатику, он отдаёт честь.

## Как получить APK — самый простой способ (ничего не устанавливая)

APK собирается сам на GitHub, в облаке. На компьютер ничего ставить не надо.

1. Откройте репозиторий на github.com → вкладка **Actions**.
2. Слева выберите **«Собрать APK „До отпуска“»**.
   - Сборка запускается сама после каждого изменения в папке `do-otpuska`.
   - Запустить вручную можно так: кнопка **Run workflow** → выберите ветку → **Run workflow**.
3. Подождите 3–5 минут, пока рядом с запуском не появится зелёная галочка ✅.
4. Нажмите на этот запуск, прокрутите вниз до раздела **Artifacts** и скачайте
   **do-otpuska-apk**. Скачается zip-архив, внутри него файл `do-otpuska.apk`.

## Как установить на телефон (Android)

1. Перекиньте `do-otpuska.apk` на телефон: через Telegram «Избранное», по кабелю
   или через Google Диск. Если скачали zip прямо на телефон, сначала распакуйте его.
2. Нажмите на файл в телефоне.
3. Телефон скажет, что установка из неизвестных источников запрещена. Нажмите
   **Настройки** и включите **«Разрешить из этого источника»** для приложения,
   через которое открываете файл (Telegram, «Файлы», Chrome…). Вернитесь назад.
4. Нажмите **Установить**. Если появится Google Play Защита с вопросом
   «Неизвестное приложение», выберите **«Всё равно установить»**: приложение
   просто не публиковалось в Play Маркете, это нормально.
5. На рабочем столе появится иконка-самолётик **«До отпуска»**.

> На iPhone APK не ставится. Для iPhone откройте `www/index.html` через любой
> хостинг (например, GitHub Pages) в Safari и выберите «На экран Домой».

## Способ для тех, кто хочет собрать сам на компьютере

Понадобятся **Node.js** (nodejs.org, версия LTS) и **Android Studio**
(developer.android.com/studio). Обе программы бесплатные.

```bash
cd do-otpuska
npm install                 # скачать Capacitor (один раз)
npx cap sync android        # скопировать www/ в Android-проект
npx cap open android        # открыть проект в Android Studio
```

В Android Studio дождитесь, пока внизу закончится «Gradle sync», затем выберите
меню **Build → Build App Bundle(s) / APK(s) → Build APK(s)**. Справа внизу
появится уведомление, нажмите в нём **locate**: там лежит `app-debug.apk`.
Можно поступить ещё проще: подключите телефон кабелем (на телефоне в «Для
разработчиков» включите «Отладку по USB») и нажмите зелёный ▶️ Run.

**Изменили `www/index.html`?** Каждый раз выполните `npx cap sync android` и
соберите заново (или просто отправьте изменения на GitHub, и сборка пройдёт сама).

**Хотите другую иконку?** Замените картинки в `assets/` (1024×1024) и выполните
`npm run icons`.

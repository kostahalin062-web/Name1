# ⏰ Будильник на пары (Android)

Ставит серию будильников «с … по … каждые N минут» (N = 1–10) **в системное приложение «Часы»**
и подсказывает, во сколько вставать, по расписанию АлтГУ — тому же `docs/schedule.ics`, что и «Моё ДЗ».
Звонят сами «Часы», так что будильник сработает, даже если это приложение закрыто или выгружено.

**Подсказка:** первая пара − 1 ч дорога − 30 мин сборы = встать за **1,5 ч**;
с включённым «🚿 Помыться» — ещё на 1 ч раньше, за **2,5 ч**. Минуты меняются в настройках (кнопка ⚙).

## Как это работает
- «Часы» умеют ставить будильник только по времени (часы:минуты), без даты, поэтому приложение
  ставит будильники **на ближайшее утро** — в пределах 24 часов.
- Вечером (по умолчанию в 21:00) приходит уведомление «Завтра пара в … — поставить будильники?».
  Кнопка «Поставить» открывает приложение и сразу отправляет всю серию в «Часы».
  Время напоминания и его выключение — в настройках.
- Удалить или изменить будильники — в самих «Часах» (кнопка «Открыть «Часы»» на главном экране).

## Как поставить на телефон
1. Открой на телефоне релиз **budilnik-latest** в репозитории (Releases) и скачай `budilnik.apk`.
2. Установи (разреши установку из браузера/файлов).
3. Разреши уведомления (для вечернего напоминания).
4. В ⚙ Настройках нажми «Поставить пробный будильник через 2 минуты» и проверь, что он появился в «Часах».

APK собирает GitHub Actions (`.github/workflows/build-apk.yml`) при каждом изменении в `android/`.

Чтобы новые сборки ставились поверх старой, добавь в Settings → Secrets → Actions секреты
`BUDILNIK_KEYSTORE` (keystore в base64, alias `budilnik`) и `BUDILNIK_KEYSTORE_PASSWORD`.
Без них APK подписывается временным ключом, и для обновления старую версию придётся удалить.

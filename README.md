# TurboPC — прототип интерфейса ИС «Компьютерный клуб»

Лабораторная работа: техническое задание, фирменный стиль, дизайн-система, прототип шести страниц и отчёт.

| Путь | Что внутри |
|---|---|
| `tz/ТЗ.docx`, `tz/TZ.md` | Техническое задание по ГОСТ 34.602-2020, ER-диаграмма `tz/er.png` |
| `brand/` | Логотип (цветной, монохромный, белый), знак, favicon, баннер 1440×500 (SVG) |
| `prototype/` | Кликабельный HTML-прототип: `index.html` (главная), `catalog.html`, `about.html`, `account.html`, `feedback.html`, `login.html`, `register.html`, `design-system.html` |
| `screenshots/` | Скриншоты страниц, состояний и фрагментов (2×) |
| `report.docx` | Отчёт (Times New Roman 14, интервал 1,5, поля 30/15/20/20 мм) |
| `figma/` | Данные для сборки кадров в Figma |
| `tools/` | Скрипты: сборка DOCX, генерация логотипа и баннера, скриншоты, проверка ссылок, перенос в Figma |

Прототип открывается локально: `prototype/index.html`. Демо-вход: любой корректный e-mail и пароль `turbo2026`.
Состояния для демонстрации: `feedback.html?state=error`, `feedback.html?state=success`, `login.html?state=error`,
`register.html?state=error`, `account.html?modal=topup`.
